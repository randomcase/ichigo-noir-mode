# Paris Principles Foundation

This repository is operated using four principles:

1. **Guardrailed Orchestration (GO)**
   Policy before power. No blind writes.

2. **Symbolic Lifecycle Control (SLC)**
   Deprecate/archive/delete symbolically first; physical actions are exceptional.

3. **Fold -> Reuse -> Compound (FRC)**
   Convert learning into reusable templates and improve once for many repos.

4. **BLM (Betterment, Learning, Mastery)**
   Measure whether operations are improving outcomes, knowledge, and execution consistency.

## Operating posture (solo production)

- Automation enabled
- Symbolic lifecycle actions only
- Dry-run defaults
- Snapshot-first UI performance
- Full audit trail through intent + evidence logs
