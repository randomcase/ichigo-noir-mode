# Fold -> Reuse -> Compound (FRC)

## Principle
A good learning scaffold is folded and reused.

## Method
1. **Fold**: capture a lesson in code/docs/template.
2. **Reuse**: distribute it across repositories.
3. **Compound**: improve once; all inheritors gain.

## Required Artifacts
- Template baseline docs
- Policy defaults
- Snapshot contracts
- Ledger examples
- Health-check workflow

## Success Signal
Template compliance improves while custom one-off fixes decrease.
